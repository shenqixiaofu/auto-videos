敲定的设计思路是

输入端 (FastAPI)：{gender: "女", age: "20", location: "桂林"}

这个是一个任务，定时执行的

Action A (场景拆解)：LLM 检索“桂林”的特征，自动裂变出：漓江竹筏、阳朔西街木楼、龙脊梯田、象鼻山水月洞 这里他会随机输出一个场景

Action B (风格注入)：LLM 写实风格：烟雨朦胧感、日落金辉、清晨透亮、胶片质感 再匹配一个风格

Action C 根据这些场景 风格 性别 年龄， 锁定人物 服装背景，一致性，生成10个不同的动作也就是10个提示词， 也就是10个任务存到数据库，

那么这个页面， 肯定就是查看任务， 和创建任务的地方

这里创建任务 就是 输入端

{gender: "女", age: "20", location: "桂林"
